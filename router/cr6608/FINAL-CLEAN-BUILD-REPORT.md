# CR6608 — تقرير البناء النهائي النظيف (Smart AP + درايفر 38 حقيقي)

**الملف:** `cr6608-final-clean-openwrt-dsa-38-sysupgrade.bin`
**التاريخ:** 2026-07-07

هذا البناء = **بناؤك المبني من المصدر** (النواة والدرايفر بايت-ببايت كما بنيتَهما) + **دمج واجهاتي
وميزاتي** + **تطبيق مواصفاتك الـ12** كلها — بدون أي لمس للطاقة/الـPA/الدرايفر.

## 2) الطاقة والدرايفر (لم تُلمَس — بايت-ببايت)
| البند | القيمة |
|---|---|
| `mt7915e.ko` sha256 | `715e6bf40d0836178248905d73d5d4a87f22cfa8dc92b82af070786cfffef8f0` (مطابق لبنائك) |
| المعامل | `cr6608_rf_38dbm` (bool) — موجود |
| البانر | `CR6608-RF-38DBM-LINEAR enabled` — موجود |
| `cr6608_rf_35dbm` / `CR6608-RF-35DBM` | **غير موجود إطلاقاً** (grep فارغ) |
| `/etc/modules.d/mt7915e` | `mt7915e cr6608_rf_38dbm=1` (يُحمّل المعامل وقت الإقلاع) |
| `/etc/modprobe.d/mt7915e.conf` | `options mt7915e cr6608_rf_38dbm=1` |
| txpower (كلا الراديوين) | **38** (طلب/سقف برمجي) |

**الحقيقة الهندسية (بلا أرقام وهمية):** 38 هو *طلب/سقف* — الخرج الفعلي يبقى محدودًا بالـPA عند
~30 dBm EIRP. لا فيرموير يشعّ 38 dBm؛ ذلك يحتاج PA خارجي أو هوائي أعلى ربحًا. الرابط 1200Mbps
يأتي من HE80 + 2 تيّار + short-GI ومستقل عن رقم الطاقة.

## 4) DHCP مقفول + IPv6 مقفول (افتراضيًّا)
- **DHCP:** `dhcp.lan.ignore='1'`, `dhcpv4/dhcpv6='disabled'`, `odhcpd.maindhcp='0'`,
  وخدمتا `dnsmasq` و`odhcpd` **معطّلتان** — الجهاز لا يوزّع أي IP (يعمل كـ AP خلف الميكروتك).
- **IPv6:** `network.lan.delegate='0'`, حُذف `ula_prefix` و`wan6` و`ip6assign`,
  و`ra/ndp/dhcpv6='disabled'` — لا RA ولا DHCPv6 ولا NDP ولا ULA.

## 5) الوقت + الدخول
- **المنطقة الزمنية:** `Asia/Aden` (`<+03>-3`) + خوادم NTP مضبوطة.
- **الدخول:** root / admin. تدفّق: لوحة Smart AP السوداء → الداشبورد → زر "OpenWrt" (`/cgi-bin/luci/`)
  → LuCI/Argon. الخروج يعمل، لا حلقة دخول. كل التحويلات **مسارات نسبيّة** (لا IP مثبّت في الواجهة).

## 6) لا عناوين IP مثبّتة في الواجهة (redirects)
لا يوجد أي `location.replace`/`href` بعنوان `192.168.1.1` أو `221.221.221.1` في لوحة Smart AP
أو صفحة الدخول أو `index.html`. زر OpenWrt = `/cgi-bin/luci/` (نسبي)، وصفحة LuCI login تُحوّل بـ
`location.replace('/')` (نسبي). القيم `192.168.1.1` المتبقية هي: (1) قيمة افتراضية لحقل "استضافة" (ping)،
(2) عنوان الإدارة الفعلي للجهاز (خادمي، شرعي)، (3) ملفات LuCI الأصلية (flash/connections).

## 7) الميزات المدموجة (من نسخي)
لوحة Smart AP كاملة (بطاقات PRO، رسوم متجاوبة مع الثيم)، ثيم Argon، الإعدادات السريعة (الويزارد
موصول بالتنقّل، كل الحقول تُرسل)، **زر الحفظ/التطبيق بضغطة واحدة** (أُزيل التأكيد المزدوج عن الحفظ
اليومي، وبقي على الحذف/الريبوت/الريست)، عزل المنافذ + VLAN مع شبكة أمان الإدارة، الميش (المرسِل +
الجوّالات تظهر)، شفاء `smartap` التالف من `/rom`، وواجهة إنقاذ `221.221.221.221` على `br-lan`.

## طريقة الفلاش
LuCI → System → Backup/Flash Firmware، أو `sysupgrade -v <الملف>`. إن ظهر تحذير توافق النسخة
(image 1.1 / device 1.0) استخدم **Force** — نفس سلوك بنائك الأصلي.
