# مدير الكروت — Card Manager

نظام كامل لإنشاء وطباعة كروت **اليوزر منجر** و**الهوتسبوت** لأنظمة MikroTik، مكوّن من تطبيقَي أندرويد:

| التطبيق | الملف | لمن |
|---|---|---|
| مدير الكروت | `CardManager.apk` | المشتركون — فترة تجريبية أسبوع ثم ترخيص |
| لوحة التراخيص | `CardManager-Admin.apk` | أنت فقط — إصدار مفاتيح التفعيل |

> ⚠️ لا تشارك ملف لوحة التراخيص مع أحد. من يملكه يستطيع إصدار مفاتيح لأي جهاز.

## نظام الاشتراكات

- التطبيق يعمل **٧ أيام** تجريبية من أول تشغيل، ثم يتوقف ويطلب مفتاح ترخيص.
- كل مفتاح **مربوط ببصمة جوال واحد** — لا يعمل على جوال آخر إطلاقاً.
- التوقيع بخوارزمية **ECDSA P-256**: المفتاح الخاص في تطبيق الأدمن فقط، وتطبيق المشترك يحمل المفتاح العام ويتحقق به. فحتى لو فُكّ تطبيق المشترك لا يمكن توليد مفاتيح منه.
- المدد المتاحة: تجريبي، شهر، ثلاثة أشهر، سنة، دائم.
- إرجاع ساعة الجوال للخلف لا يمدد التجربة (يُحفظ آخر وقت مشاهَد ويُقارن به).
- التحقق يتم **بدون إنترنت** — لا حاجة لخادم.

### خطوات التفعيل

1. المشترك يفتح التطبيق فيظهر له **رمز جهازه** (٨ أحرف)، ويرسله لك بضغطة زر عبر واتساب.
2. تفتح لوحة التراخيص، تلصق الرمز، تكتب اسم المشترك، تختار المدة، وتضغط **إصدار المفتاح**.
3. ترسل له المفتاح، يلصقه في تطبيقه ويضغط **تفعيل**.

كل ترخيص تصدره يُحفظ في سجل داخل لوحة التراخيص مع اسم المشترك ورمز جهازه وتاريخ الانتهاء.

## المميزات

### الاتصال بالراوتر
- محلياً عبر IP، أو **عن بعد** عبر دومين أو IP Cloud DDNS
- اتصال مشفّر **api-ssl** على المنفذ 8729 مع قبول الشهادة الذاتية للراوتر
- مهلة اتصال قابلة للضبط للشبكات البطيئة
- حفظ عدة راوترات والتبديل بينها
- وضع محلي للعمل بدون راوتر (تصميم وطباعة فقط)

### الإحصائيات
تُقرأ مباشرة من الراوتر: إجمالي كروت الهوتسبوت، مستخدمو اليوزر منجر، الكروت المستهلكة وغير المستهلكة، المتصلون الآن مع استهلاكهم — بالإضافة لإحصائيات التطبيق (المطبوع اليوم والمبيعات).

### إنشاء الكروت
- توليد دفعات حتى ٥٠٠٠ كرت: العدد، البادئة، **عدد الأرقام/الحروف**، أرقام فقط أو حروف، كلمة مرور مطابقة أو مستقلة، السعر والصلاحية والباقة
- استيراد CSV بتعرّف تلقائي على الأعمدة (يدعم صيغة `gen_export.csv` في RouterOS v7)
- جلب المستخدمين من الهوتسبوت واليوزر منجر (v6 و v7 تلقائياً)
- رفع الدفعات إلى الراوتر مع شريط تقدم

### تخطيط الصفحة
- مقاسات ورق: A4، A5، A3، Letter — عمودي أو أفقي
- **توزيع تلقائي** أو تحديد يدوي لعدد الأعمدة والصفوف (مثلاً ٤ بالعرض × ١٠ بالطول)
- تحكم مستقل بالمسافة الأفقية والرأسية والهوامش
- أربعة أنماط لعلامات القص: بدون، إطار، زوايا، خطوط متقطعة
- توزيعات جاهزة: 2×5، 3×8، 4×10، 5×13
- **معاينة حية للصفحة كاملة** قبل الطباعة

### التصميم والطباعة
- محرر قوالب بالسحب والإفلات، خلفية من معرض الجوال، مقاسات كرت جاهزة
- رمز QR: دخول تلقائي للهوتسبوت، أو اتصال واي فاي، أو مستخدم/رمز
- طباعة A4 كملف PDF أو عبر نظام أندرويد (WiFi/USB)
- طباعة حرارية 58/80مم بلوتوث أو شبكة (TCP 9100) مع تحكم بارتفاع الكرت والتغذية والقص
- العربية تُطبع كصورة نقطية فتظهر صحيحة على أي طابعة

### الباقات والتقارير
- جلب باقات الهوتسبوت بسرعاتها ومددها، تسعيرها، وإنشاء باقات جديدة على الراوتر
- حذف المستخدمين المنتهية صلاحيتهم
- تقارير مبيعات يومية وشهرية، الأكثر مبيعاً، وسجل الدفعات مع إعادة الطباعة

## البناء

يُبنى التطبيقان تلقائياً عبر GitHub Actions. حمّلهما من صفحة Releases تحت وسم `card-manager-latest`.

محلياً:

```bash
cd CardManagerApp
gradle assembleSubscriberDebug   # تطبيق المشترك
gradle assembleAdminDebug        # لوحة التراخيص
```

### تغيير مفاتيح الترخيص

المفاتيح الحالية مولّدة لهذا المشروع. لتوليد زوج جديد خاص بك:

```bash
java -e 'KeyPairGenerator g = KeyPairGenerator.getInstance("EC"); ...'
```

ثم ضع المفتاح الخاص في `app/src/admin/java/com/binwaps/cardmanager/AdminKeys.kt`
والمفتاح العام في `PUBLIC_KEY_B64` داخل `app/src/main/java/com/binwaps/cardmanager/license/License.kt`.
