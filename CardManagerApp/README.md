- أعيد فرض بوابة الاشتراك: شجرة الطباعة والإدارة لا تُعرض بلا اشتراك أو تجربة صالحة من الخادم.
- كلا التطبيقين يستخدم عنوان HTTPS نفسه. مفتاح مزوّد الخدمة العام مثبت داخل APK، ولا يوجد جلب مفتاح تلقائي موثوق من الشبكة.
- أصبح تطبيق الإدارة عميلاً لخادم الاشتراكات فقط. حُذف `AdminKeys.kt` وإصدار التراخيص المحلي، ومفتاح توقيع APK القديم المكشوف من المصدر.
- طلبات المشترك موقعة بمفتاح جهاز في Android Keystore ومقيدة بالمسار والوقت وnonce. تغيير البريد أو نسخ رمز الجهاز وحده لا يمنح صلاحية.
- تُحفظ الاستجابة الأصلية الموقعة ويعاد التحقق منها. لا تُقبل مفاتيح محلية أو حالة قبول غير موقعة بديلاً لقرار السيرفر.
- مهلة العمل دون اتصال لا تتجاوز 72 ساعة ولا تاريخ انتهاء الاشتراك؛ بعد إعادة تشغيل الهاتف يلزم اتصال جديد بالخادم. الإيقاف يصل عند أول تحقق، والفحص أثناء فتح التطبيق كل 5 دقائق. لا يمكن تطبيق إيقاف لحظي على هاتف غير متصل.
- تحرس طبقة الطباعة البدء والاستئناف، وتراجع الاشتراك بين أجزاء PDF وبين الكروت الحرارية؛ تحفظ الأجزاء المكتملة.
- رمز الإدارة مشفر بمفتاح Android Keystore. النسخ الاحتياطي التلقائي للبيانات الحساسة معطل.
- الخادم يرفض الطلبات غير الموقعة، وخطة مجهولة، ونقل جهاز مربوط بحساب آخر. تخزين التراخيص ذري؛ قاعدة تالفة توقف الخدمة ولا تعيد التجارب من الصفر.
- أزيل بناء أوامر JavaScript من بيانات الحسابات داخل صفحة الإدارة لتجنب حقنها.
- إعداد Release يستخدم R8 وتقليص الموارد، ومفتاح توقيع الإنتاج لا يدخل GitHub Actions.
