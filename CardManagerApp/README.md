# مدير الكروت — Card Manager

تطبيق أندرويد كامل لإنشاء وطباعة كروت **اليوزر منجر (User Manager)** و**الهوتسبوت (Hotspot)** لأنظمة MikroTik.

## المميزات

- **إدارة المستخدمين**
  - توليد دفعات كروت عشوائية (العدد، البادئة، الطول، أرقام/حروف، كلمة مرور مطابقة أو مستقلة، السعر، الصلاحية، الباقة)
  - استيراد ملفات CSV المُصدَّرة من اليوزر منجر أو الهوتسبوت (تعرّف تلقائي على الأعمدة والفواصل)
  - الاتصال المباشر بالراوتر عبر RouterOS API (منفذ 8728): جلب مستخدمي الهوتسبوت، ورفع الدفعات المولَّدة إلى الراوتر
- **مصمم القوالب**
  - رفع صورة خلفية للقالب من الجوال
  - سحب وإفلات الحقول على الكرت (اسم المستخدم، كلمة المرور، السعر، الصلاحية، الباقة، الرقم التسلسلي، نص ثابت، رمز QR)
  - تحكم بحجم الخط واللون والخط العريض لكل حقل
  - أبعاد كرت قابلة للتخصيص بالمليمتر، ألوان خلفية وإطار وزوايا دائرية
  - رمز QR: رابط دخول تلقائي للهوتسبوت، أو اتصال واي فاي، أو اسم المستخدم/كلمة المرور
  - قوالب متعددة مع نسخ وتعديل وحذف
- **الطباعة**
  - تصدير PDF على ورق A4 كشبكة كروت مع علامات قص وهوامش وتباعد قابل للضبط
  - طباعة عبر نظام أندرويد على أي طابعة (WiFi/USB)
  - طباعة حرارية عبر البلوتوث (ESC/POS) بعرض 58مم أو 80مم مع تحكم بارتفاع الكرت والتغذية ودقة الطابعة
- واجهة عربية كاملة (RTL)

## البناء

يُبنى APK تلقائياً عبر GitHub Actions (ملف `.github/workflows/build-card-app.yml`).
حمّل `CardManager.apk` من صفحة Releases (وسم `card-manager-latest`) أو من Artifacts في تبويب Actions.

للبناء محلياً:

```bash
cd CardManagerApp
gradle assembleDebug
```

## التقنيات

- Kotlin + Jetpack Compose (Material 3)
- ZXing لتوليد رموز QR
- DantSu ESCPOS-ThermalPrinter-Android للطباعة الحرارية
- me.legrange:mikrotik لعميل RouterOS API
- kotlinx.serialization لتخزين القوالب والإعدادات
