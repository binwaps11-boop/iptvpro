# CR6606 — تصميم العتاد والهوائيات لأقصى أداء WiFi-6 / AX1800

دليل هندسي لرفع المدى والسرعة على Xiaomi CR6606 (MT7621A + mt7915، MT7905DAN/MT7975DN،
2×2 2.4G + 2×2 5G). يركّز على **مكاسب حقيقية** (EIRP نظيف + RX أفضل + ثبات حراري)،
وليس أرقاماً وهمية. **لا يتطلب لمس MAC/EEPROM/caldata.**

> ⚠️ تحذير سلامة عتاد: **لا تشغّل الراديو أبداً بلا هوائيات موصّلة.** الإرسال بلا حمل
> هوائي يعكس القدرة على الـ PA ويُتلفه. أوقف Wi-Fi قبل فكّ الهوائيات.

---

## 1) لماذا الهوائيات أهم من رقم الباور
- باور الـ PA سقفه فيزيائي (~20–22 dBm/سلسلة) — لا يتغيّر.
- **كسب الهوائي يضاف مباشرة للـ EIRP** وللاستقبال (RX) معاً:
  - EIRP = باور_السلسلة + دمج 2×2 (~+3dB) + **كسب الهوائي (dBi)**.
  - كل **+3 dBi** ≈ مضاعفة المدى النظري في الاتجاه المعزّز، **بلا تشويه وبلا مخالفة**.
- المدى **ثنائي الاتجاه**: الهوائي الأعلى كسباً يحسّن سماع الراوتر للهاتف الضعيف (RX) — وهذا ما لا يفعله رفع باور الإرسال وحده.

---

## 2) ترقية الهوائيات (الأعلى أثراً)
CR6606 هوائياته **داخلية (PCB/ربون)** متصلة غالباً بموصلات **U.FL/IPEX** على اللوحة.

### الخيار A — هوائيات خارجية RP-SMA قابلة للتوجيه (موصى به)
- **العدد:** 4 هوائيات (2 لكل باند) — للحفاظ على **2×2 لكل باند**.
- **النوع/الكسب:**
  - 2.4GHz: ثنائي الباند **5 dBi** omni (سوط).
  - 5GHz: ثنائي الباند **5–7 dBi** omni.
  - أو هوائيات **dual-band 2.4/5** 5–6 dBi (أبسط، 4 قطع).
- **الوصلات:** **U.FL→RP-SMA pigtails** + فتحات RP-SMA على الغطاء.
- **MIMO diversity (مهم للـ2×2):**
  - باعد بين هوائيي نفس الباند **≥ نصف الطول الموجي** (2.4G ≈ 6cm، 5G ≈ 3cm).
  - **تنويع الاستقطاب:** هوائي عمودي + الآخر مائل 45° → أداء MIMO/البيمفورمنغ أفضل في الانعكاسات.

### الخيار B — هوائيات اتجاهية (Panel/Yagi) لمسافة في اتجاه واحد
- panel 8–12 dBi (5G) لتغطية طابق/غرفة بعيدة في خط واحد — مكسب EIRP كبير في الاتجاه، أضيق تغطية.

> **لا تتجاوز ما يبقي EIRP ضمن حد بلدك** (هوائي عالٍ جداً + باور أقصى قد يتخطّى الحد القانوني).

---

## 3) التبريد (يحافظ على الباور ويمنع throttle)
رفع الباور + حمل WiFi6 = حرارة → الدرايفر قد يخفض القدرة (thermal). الحل:
- **مشتت حراري لاصق** على شريحة MT7621 وعلى FEM (MT7905/MT7975) عبر **وسادة حرارية**.
- تحسين تهوية الغطاء (الفتحات موجودة) أو **مروحة 5V صغيرة** صامتة.
- الفائدة: باور **مستقر** تحت الحمل + عمر أطول + ثبات (أقل reboot حراري).

---

## 4) التغذية (ثبات تحت الحمل)
- المصنع: **12V / 1A**. تحت حمل WiFi6 كامل قد يقترب من الحد.
- استخدم محول **12V / 2A** جيد (نفس القطبية) → جهد ثابت، أقل أخطاء/إعادة تشغيل.
- **لا** تستخدم محولاً رخيصاً غير منظّم.

---

## 5) "التعاريف" البرمجية القوية (مفعّلة في نسخة wifi6-pro)
كلها ميزات AX1800 حقيقية في mt7915:
| الميزة | الأثر الحقيقي |
|---|---|
| **HE Beamforming (SU+MU)** | تركيز الإشارة نحو العميل → مدى/سرعة أعلى |
| **MU-MIMO** | خدمة عدة عملاء معاً → إنتاجية أعلى |
| **OFDMA (HE)** | كفاءة مع عملاء كثيرين/ترافيك صغير → كمون أقل |
| **BSS Coloring** | أداء أفضل في الازدحام |
| **802.11k/v** | تنقّل أسرع بين الباندات/الأكسس |
| **cell_density=0 + disassoc_low_ack=0** | لا يطرد العملاء البعيدين → **مدى أكبر فعلاً** |
| **legacy_rates=0** | إلغاء معدّلات 802.11b البطيئة → كفاءة هواء أعلى |
| **flow offload sw+hw** | إنتاجية WAN أعلى، CPU أقل |
| **SQM/cake (اختياري)** | كمون منخفض تحت الحمل (فعّله إن خطّك < ~300Mbps) |

---

## 6) إعداد القنوات الأمثل (مضبوط)
- **2.4GHz:** HE20 + أفضل قناة (1/6/11) عبر ACS → أفضل اختراق ومدى.
- **5GHz:** HE80 + **149** (UNII-3): أعلى باور مسموح + بلا تأخير DFS. لمسافة أبعد جرّب **HE40 على 149** (SNR أعلى للحافة).
- تجنّب قنوات DFS (52–144) إن أردت بدء فوري بلا CAC.

---

## 7) خطة قياس النتيجة (بالأرقام، لا كلام)
```sh
# قبل/بعد أي ترقية (نفس المكان ونفس العميل):
sh /root/cr6606-ab-compare.sh save before
# ... طبّق الترقية (هوائي/نسخة/تبريد) ...
sh /root/cr6606-ab-compare.sh save after
sh /root/cr6606-ab-compare.sh report
# قياس RF دقيق (اختياري): محلّل طيف/مقياس قدرة + attenuator معاير، أو SDR نسبي.
```
**الحكم:** ترقية الهوائي يجب أن ترفع **Signal للعميل** و**TX/RX bitrate** وتخفض **Retries/Failed**. إن لم تتحرّك الأرقام → الترقية لم تنفع في موضعك، جرّب توجيهاً/نوعاً آخر.

---

## 8) ترتيب الأولوية (أعلى عائد أولاً)
1. **هوائيات خارجية أعلى كسب + تنويع استقطاب** ← أكبر مكسب مدى/سرعة حقيقي.
2. **نسخة wifi6-pro** (Beamforming/MU/OFDMA/11k-v + max-clean power).
3. **تبريد** (يحافظ على الباور تحت الحمل).
4. **تغذية 12V/2A**.
5. **القناة 149 + HE80/HE40** حسب المسافة.
6. (اختياري) **SQM** للكمون، **مكبّر خارجي** فقط لاختبار مخبري قانوني.
```
لا شيء هنا يلمس MAC/EEPROM/caldata، وكل بند **يُقاس** بـ cr6606-ab-compare.sh.
```
