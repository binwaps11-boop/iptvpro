# خدمة اشتراكات مدير الكروت — بروتوكول الجهاز الموقع

هذه نسخة مُعدّة ولم تُنشر على VPS بعد. نجح اختبار البروتوكول المحلي في 29 حالة.

## تجهيز المالك

استخدم مجلد `license-server` من `CardManager_Private_Deployment.zip`؛ يحتوي مفتاح الخدمة الخاص الموافق للمفتاح العام المثبت داخل التطبيق. الملف خاص بصاحب النظام؛ لا يرفع إلى GitHub ولا يوزع على المشتركين.

تحتاج Node.js 22 أو أحدث وNginx ونطاق HTTPS بشهادة صالحة. بعد نسخ المجلد إلى VPS، شغّل من داخله:

```bash
sudo LICENSE_DOMAIN=license.your-domain.tld bash install.sh
```

استبدل اسم النطاق بعنوانك الفعلي. السكربت يتطلب وجود الشهادة مسبقاً في مسار Let's Encrypt، أو تحديد `LICENSE_CERT` و`LICENSE_TLS_KEY`. لن يخمن نطاقاً أو ينشئ شهادة غير معروفة.

ينشئ خدمة مستقلة `cardlicense-v2`، ومجلد بيانات `/var/lib/cardlicense-v2`، ويستمع على loopback:8091 خلف TLS. لا يغير خدمات IPTV أو منافذها. يتأكد من تطابق مفتاح التوقيع ويرفض استبدال مفتاح موجود مختلف.

اقرأ رمز الإدارة من `/etc/cardlicense-v2.env` على خادمك وأدخله في APK لوحة التراخيص. أدخل عنوان HTTPS نفسه في التطبيقين. المشترك يسجل بياناته ويرسل طلبه؛ توافق عليه من الإدارة ثم يضغط تحقق الآن في تطبيق الطباعة.

أي قاعدة قديمة لا تملك مفاتيح أجهزة تحتاج ربطاً مصرحاً من الإدارة ثم تسجيل الجهاز من جديد. التثبيت الجديد لا يستورد قاعدة خدمة قديمة تلقائياً. احتفظ ببياناتها قبل أي ترحيل.

## الأمن والبروتوكول

طلبات `/api/register` و`/api/check` و`/api/request` و`/api/routers` تتطلب غلافاً `{payload, signature, publicKey}`. `payload` هو base64 لبايتات JSON تتضمن حقول العملية و`path,timestamp,nonce`. توقيع DER ECDSA/SHA256. يتحقق السيرفر من المسار والوقت (5 دقائق) وعدم تكرار nonce وامتلاك المفتاح المسجل للحساب.

التسجيل الأول يربط مفتاح الجهاز. إعادة التثبيت التي تفقده تحتاج موافقة نقل/إعادة ربط من الإدارة؛ لا يوجد تجاوز عبر مفتاح قديم داخل APK. هذا إثبات حيازة مفتاح، وليس تحققاً من سلامة نظام التشغيل أو attestation.

ردود التراخيص ECDSA P-256/P1363 فوق البايتات الأصلية، وتشمل nonce والجهاز ومفتاح العميل والمدة. المفتاح الخاص لا يدخل التطبيق ولا المستودع.

لوحة API الإدارية تتطلب `x-admin-token` بطول 32 بايت على الأقل. النقل لا يستولي على جهاز حساب آخر. شهادة HTTPS مطلوبة من التطبيقين؛ endpoint المشترك يرفض إعادة التوجيه.

تصل حالة الإيقاف عند أول تحقق؛ قد يعمل الجهاز غير المتصل حتى نهاية مهلة موقعة لا تتجاوز 72 ساعة أو انتهاء الاشتراك، أيهما أقرب. إعادة تشغيل الهاتف تستلزم اتصالاً لتجديد الثقة بالوقت.

## الاختبار

```bash
node test.js
```

تشغيل محلي تجريبي يولد مفتاحاً مؤقتاً لا يعمل مع APK المالك. خدمة الإنتاج تستعمل `REQUIRE_EXISTING_KEY=1` لمنع توليد مفتاح مختلف بالخطأ. لا يُعد نجاح الاختبار المحلي إثباتاً لنشر HTTPS أو تشغيل APK.
