# ضبط الواي-فاي وإصلاح مشاكل الجوال — Xiaomi CR6608 (OpenWRT 24.10)

> **مهم:** الملف الذي رفعته (`...cr6608...sysupgrade.bin`) هو **فيرموير OpenWRT
> مترجم** للراوتر. لا يمكن تعديل "الباور / التدفق / الخط" بداخل هذا الملف الثنائي —
> هذه إعدادات **تشغيل (UCI)** على الراوتر نفسه. لذلك الحل الصحيح والآمن هو تطبيق
> الإعدادات على الراوتر، **وليس** تعديل الـ `.bin` (تعديله يعرّض الجهاز للتلف).

## كيف تطبّق

```sh
scp apply-tuning.sh root@192.168.1.1:/tmp/
ssh root@192.168.1.1
sh /tmp/apply-tuning.sh
```

السكربت يأخذ نسخة احتياطية أولاً، وقابل لإعادة التشغيل بأمان. للتراجع:

```sh
cp /tmp/wireless.bak /etc/config/wireless && wifi reload
```

⚠️ **قبل التشغيل:** افتح `apply-tuning.sh` وغيّر `COUNTRY="SA"` لرمز دولتك.
رمز الدولة الصحيح هو ما يفتح أعلى باور وأفضل قنوات مسموحة قانونياً.

## ماذا يعالج كل طلب من طلباتك

| طلبك | ما تم عمله | الواقع/الحد |
|------|-----------|--------------|
| الباور 30 | `txpower=30` على الراديوين | الراوتر **يقصّه** للحد القانوني/الهاردوير (عادة ~20–23 dBm). لا يوجد إعداد يكسر هذا الحد بأمان. |
| التدفق / السرعة 300×300 | تفعيل **80MHz (HE80)** على 5GHz + WMM + Beamformer | الـ300 Mbit/s تتحقق **فقط** بإشارة جيدة (أفضل من ‑65 dBm). صورتك تُظهر **‑85 dBm** و**20MHz** = لذلك السرعة 97 فقط. الحل الفعلي: عرض القناة 80MHz **+ تقريب الجهاز / تحسين المكان**. |
| الخط فاسخ / غير مستقر | تثبيت قناة، `disassoc_low_ack=0`، roaming (k/v) | عدم الفصل عند ضعف لحظي + انتقال أنعم. |
| التداخل على الجوال | 2.4GHz على **20MHz** + قناة auto/نظيفة | يقلّل التداخل في الباند المزدحم. ثبّت 1/6/11 يدوياً إن استمر. |
| الإنجليزي لا يتحول | `luci.main.lang=en` + تثبيت `luci-i18n-base-en` | سبب عدم التحويل غالباً **نقص حزمة اللغة** في الفيرموير. السكربت يثبّتها إن توفر إنترنت. |
| بطء فتح الإعدادات بالجوال | `uhttpd` gzip + مهلات أطول | يسرّع تحميل الواجهة. ملاحظة: ضعف الواي-فاي نفسه (‑85) سبب رئيسي للبطء. |
| السلاسة / الارتباط | WMM + OFDMA/MU-MIMO (افتراضي بوضع HE) + 802.11k/v | أداء أنعم خصوصاً مع أجهزة متعددة. |

## لماذا لم أعدّل ملف الـ `.bin`؟

1. هو أرشيف فيه `kernel` + `root` (squashfs مضغوط). فكّه وإعادة تجميعه وحرقه =
   خطر **brick** (تلف دائم) إن اختلف حجم/تواقيع الصورة.
2. حتى لو عُدّل، فإن الباور/التدفق **ليست قيماً ثابتة فيه** — تُحدَّد وقت التشغيل
   من `/etc/config/wireless` ومن قيود الدولة والهاردوير وجودة الإشارة.
3. الطريقة المعتمدة في OpenWRT لهذه الإعدادات هي UCI — وهذا ما يفعله السكربت.

## للتحقق بعد التطبيق

```sh
iwinfo            # يعرض القناة، العرض (يجب أن يظهر 80MHz على 5G)، والباور الفعلي
iw dev            # تفاصيل الواجهات
logread | grep -i wifi
```
