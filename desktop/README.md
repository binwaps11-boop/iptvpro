# IPTV Pro Desktop — مشغّل بث مباشر للابتوب (شبيه Jellyfin)

تطبيق سطح مكتب خفيف لتشغيل **القنوات المباشرة + الأفلام + المسلسلات (مع الحلقات)**
من قوائم **M3U / M3U URL / Xtream Codes**، مع **Stream Proxy** مدمج، و**وصول شبكي مثل Jellyfin**،
ودعم كامل لتوجيه البث عبر **بروكسي/VPN خاص بك** (HTTP أو SOCKS5) لتجاوز الحظر الجغرافي بشكل شرعي.

> مكتفٍ ذاتياً بالكامل: يعمل بـ Node.js فقط، **بدون أي حزم npm** ولا قاعدة بيانات.

## ✨ المحتوى المدعوم

| القسم | المصدر |
|---|---|
| 📡 **المباشر** | كل قناة على حدة (HLS) — من Xtream أو M3U |
| 🎬 **الأفلام** | مكتبة VOD من Xtream مع التقديم/الترجيع (Range) |
| 📺 **المسلسلات** | قائمة المسلسلات ← المواسم ← الحلقات (تُجلب عند فتح المسلسل) |

---

## ⚡ التشغيل السريع

المتطلب الوحيد: تثبيت [Node.js](https://nodejs.org) (إصدار 18 أو أحدث).

```bash
cd desktop
node server.js
```

ثم افتح المتصفح على: **http://localhost:8787**

أو استخدم المُشغّل الذي يفتح المتصفح تلقائياً:

- ويندوز: انقر مرتين على `start.bat`
- لينكس/ماك: `./start.sh`

> لتغيير المنفذ: `PORT=9000 node server.js`

## 📺 طريقة الاستخدام

1. اضغط **«＋ المصادر»** وأضف اشتراكك. **للأفلام والمسلسلات استخدم تبويب Xtream Codes**
   (لأن قوائم M3U تعطي القنوات فقط، بينما Xtream يعطي الأقسام الثلاثة منظّمة):
   - **Xtream Codes**: رابط السيرفر + اسم المستخدم + كلمة المرور.
     > مثال: إن كان رابطك `http://ms.example.com/get.php?username=USER&password=PASS&...`
     > فأدخِل السيرفر `http://ms.example.com` والمستخدم `USER` وكلمة المرور `PASS`.
   - **رابط M3U** أو **لصق M3U**: للقنوات المباشرة فقط.
2. بدّل بين التبويبات أعلى الصفحة: **📡 المباشر / 🎬 الأفلام / 📺 المسلسلات** (يظهر عدد كل قسم).
3. القنوات/الأفلام مصنّفة حسب الفئات مع بحث فوري. اضغط أي عنصر لتشغيله.
4. للمسلسلات: اضغط المسلسل ← تظهر المواسم والحلقات ← اضغط أي حلقة لتشغيلها.

تُحفظ بياناتك محلياً في ملف `config.json` (لا يُرفع إلى Git).

## 🖥️ الوصول من أجهزة أخرى + HDMI (مثل Jellyfin)

عند التشغيل سيطبع الخادم عنواناً شبكياً، ويظهر أيضاً أعلى يسار الواجهة:

```
من أجهزة الشبكة:  http://192.168.x.x:8787
```

- **عبر الشبكة (كيبل شبكة أو واي‑فاي):** افتح هذا العنوان من متصفح **التلفزيون الذكي / الجوال / أي لابتوب**
  على نفس الشبكة — تماماً مثل Jellyfin. (الخادم يستمع على كل الواجهات `0.0.0.0`.)
- **عبر HDMI:** وصّل اللابتوب بالتلفزيون بكيبل HDMI، شغّل القناة، ثم اضغط زر
  **«⛶ ملء الشاشة (HDMI)»** في المشغّل — ستظهر القناة بملء شاشة التلفزيون.
  (ملاحظة: HDMI خرج صورة من نظام التشغيل؛ التطبيق يوفّر ملء الشاشة، وتمديد/نسخ الشاشة يتم من إعدادات العرض في ويندوز/ماك.)

## 🌎 تجاوز الحظر الجغرافي — إعداد VPN/بروكسي المكسيك

كثير من أخطاء `403` في IPTV سببها أن المحتوى **متاح فقط من دولة معيّنة**.
الحل الشرعي: توجيه طلباتك عبر **خادم في تلك الدولة تملك حق استخدامه**.

> ملاحظة مهمة: هذا التطبيق **لا يتجاوز أنظمة حماية Cloudflare الأمنية** (bot-detection / WAF / challenges).
> ما يفعله هو توجيه طلباتك عبر بروكسي/VPN تختاره أنت — وهذا يحل الحظر الجغرافي، وهو السبب
> الأكثر شيوعاً لخطأ 403. إن كان السيرفر يحظر سلوك البروكسي نفسه، فهذه مشكلة من المزوّد لا يمكن (ولا يجب) تجاوزها.

### كيف تحصل على بروكسي/VPN مكسيكي؟

أمامك خياران:

**أ) بروكسي SOCKS5/HTTP مكسيكي** (الأسهل للدمج داخل التطبيق):
- اشترِ بروكسي سكني/مركز بيانات من دولة المكسيك (مزوّدون كثر يقدّمون `host:port` + مستخدم/كلمة مرور).
- أو شغّل خادمك الخاص (مثل VPS مكسيكي) عبر `ssh -D 1080 user@mx-server` للحصول على SOCKS5 على `127.0.0.1:1080`.

**ب) تطبيق VPN كامل** (WireGuard/OpenVPN) يوجّه كل جهازك:
- في هذه الحالة لا تحتاج إعداد البروكسي داخل التطبيق — فعّل VPN على اللابتوب وشغّل التطبيق عادياً.

### أي VPN «المناسب»؟

لا توجد إجابة واحدة — **يعتمد على بلد المزوّد الذي تشترك فيه**. القاعدة: اختر خادماً في
البلد الذي يُفترض أن يُشاهَد منه المحتوى (المكسيك في حالتك). نصائح عملية:

- **جرّب أولاً بدون VPN.** إن عملت القنوات، فلا تحتاجه أصلاً.
- إن ظهر خطأ `403` أو القناة لا تفتح، فعّل VPN/بروكسي **مكسيكي** وأعد المحاولة.
- فضّل **IP سكني (Residential)** على IP مراكز البيانات — كثير من المزوّدين يحظرون نطاقات مراكز البيانات.
- خيارات شائعة موثوقة تدعم WireGuard وسرعات عالية مناسبة للبث: **Mullvad، ProtonVPN، Windscribe، NordVPN** (تحقق من توفّر خادم مكسيكي لديها).
- الأخفّ والأدق للدمج داخل هذا التطبيق: بروكسي **SOCKS5 مكسيكي**، أو نفق SSH من VPS مكسيكي:
  ```bash
  ssh -D 1080 -N user@mx-vps-ip   # ثم في الإعدادات: SOCKS5 / 127.0.0.1 / 1080
  ```
- بعد التفعيل اضغط **«اختبار الاتصال وعرض IP»** — يجب أن يظهر IP مكسيكي قبل تشغيل القنوات.

> ملاحظة صدق: إن كان الحظر من **حماية Cloudflare الأمنية** (وليس جغرافياً)، فلن يحلّه أي VPN
> بالضرورة، وقد يكون قيداً مقصوداً من المزوّد. التطبيق لا يحاول كسر هذه الحماية الأمنية.

### الإعداد داخل التطبيق (للخيار أ)

1. افتح **⚙ الإعدادات → بروكسي / VPN خاص بك**.
2. فعّل «توجيه كل الطلبات عبر البروكسي/VPN».
3. اختر النوع (`HTTP/HTTPS` أو `SOCKS5`) وأدخل `host` و`port` (و المستخدم/كلمة المرور إن وُجدت).
4. اضغط **«اختبار الاتصال وعرض IP»** — يجب أن يظهر عنوان IP مكسيكي.
5. احفظ، ثم شغّل القناة. كل طلبات البث ستمر الآن عبر الخادم المكسيكي.

## 🧱 البنية

```
desktop/
├── server.js            خادم Node نقي: ملفات ثابتة + API + Stream Proxy + توجيه بروكسي
├── public/
│   ├── index.html       الواجهة (RTL، تصميم داكن)
│   ├── styles.css
│   └── app.js           منطق الواجهة + مشغّل hls.js
├── config.example.json  نموذج الإعدادات
├── start.sh / start.bat مُشغّلات سريعة
└── package.json
```

### كيف يعمل الـ Proxy؟
- `GET /proxy?u=<URL>` يجلب المورد البعيد، وإن كان `m3u8` يعيد كتابة كل
  روابط الأجزاء والمفاتيح لتمر بدورها عبر `/proxy` (فيُحل CORS وتُطبّق Headers والبروكسي على كل جزء).
- أجزاء الفيديو (`.ts`/`.m4s`/المفاتيح) تُمرَّر مباشرة (streaming).
